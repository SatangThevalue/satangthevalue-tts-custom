# 02. Slicing with Breath Preservation (`src/audio/slicer.py`)

## 1. ปัญหาของ VAD ทั่วไป (The Unnatural Robotic Speech Issue)
เครื่องมือตัดต่อเสียงทั่วไปมักตัดจุดที่ระดับสัญญาณเสียงเงียบ (Silence Removal) ส่งผลให้:
1. **ตัดเสียงสูดลมหายใจ (Inhalation) ทิ้ง**: มนุษย์ทุกคนต้องสูดลมหายใจเข้าก่อนเปล่งเสียงประโยคยาว หากไม่มีเสียงหายใจ ผู้ฟังจะรู้สึกทันทีว่าเป็นเสียง AI
2. **ตัดหางเสียง (Plosive / Fricative Truncation)**: เสียงตัวสะกดแม่กบ/กด หรือเสียงพยางค์ท้ายมักถูกเฉือนขาด ทำให้คำพูดฟังดูกุด

---

## 2. โซลูชัน: Silero VAD + Custom Breath Padding

เราประยุกต์ใช้ **Silero VAD (ONNX Backend)** ซึ่งมีความแม่นยำสูงและใช้เวลาประมวลผลต่ำกว่า 0.05 วินาทีต่อไฟล์ 1 นาที พร้อมปรับแต่งพารามิเตอร์การตัด:

* **Window Duration**: กำหนดความยาวของแต่ละท่อนให้อยู่ในช่วง **3.0 ถึง 10.0 วินาที**
  * สั้นกว่า 3.0 วินาที: โมเดลขาดบริบทเชิงวรรณยุกต์และจังหวะ (Prosody Context)
  * ยาวกว่า 10.0 วินาที: เปลือง VRAM ตอนเทรน และเสี่ยงต่อการหลุด OOM บน GPU T4
* **Start Padding (`pad_start_ms = 150`)**: รักษาระยะก่อนเริ่มเปล่งเสียง 150 มิลลิวินาที เพื่อเก็บเสียงสูดลมหายใจเข้า
* **End Padding (`pad_end_ms = 200`)**: รักษาระยะหลังสิ้นสุดประโยค 200 มิลลิวินาที เพื่อรักษาหางเสียงสะท้อนตามธรรมชาติ

## 3. การคำนวณ Timestamp และ Resampling

Silero VAD ทำงานที่คลื่นความถี่ 16,000 Hz ระบบจึงมีขั้นตอนการแปลงกลับไปยังความถี่จริงของ Dataset (24,000 Hz):

```python
start_sample = max(0, int(ts["start"] * (sr / 16000)) - pad_start_samples)
end_sample = min(total_samples, int(ts["end"] * (sr / 16000)) + pad_end_samples)

chunk_wave = waveform[:, start_sample:end_sample]
```

## 4. Hard Guard ตรวจสอบความถูกต้อง
แต่ละท่อนเสียงที่ตัดเสร็จจะถูกส่งเข้า `validate_audio_chunk()`:
* ตรวจสอบว่าความยาวจริง `3.0 <= duration <= 10.0` วินาที
* ตรวจสอบว่าไฟล์ไม่เสียหาย (Valid PCM_16 WAV format)
* หากไม่ผ่านเกณฑ์ ไฟล์จะถูกลบทิ้งอัตโนมัติทันที
